# SquareRoot

Калькулятор квадратного корня из комплексных чисел с произвольной точностью
(1–1000 значащих цифр), аналитическим упрощением и точной формой результата.
Графический интерфейс на 5 языках: русский, English, Español, 中文, 日本語.

```
√(8)      = 2.828427124746190097603377448   точно: 2√2
√(-4)     = 2i
√(3+4i)   = 2+i
√(x^2)    упрощается до abs(x)
√(1/2)    = 0.7071067811865475244008443621  точно: √2/2
```

## Установка и запуск

Программа **не устанавливается**: это один переносимый файл. Его можно
скопировать на флешку, в любую папку или на другой компьютер с той же ОС,
и он будет работать без Python, без прав администратора и без интернета.

1. Скачайте файл для своей системы со страницы **Releases** репозитория:

   | Система | Файл |
   |---|---|
   | Windows 10/11 x64 | `SquareRoot-windows-x86_64.exe` |
   | macOS Apple Silicon (M1+) | `SquareRoot-macos-arm64.dmg` |
   | macOS Intel | `SquareRoot-macos-x86_64.dmg` |
   | Linux x86-64 (Ubuntu 24.04+, Debian 13+, Fedora 40+, Arch…) | `SquareRoot-linux-x86_64` |

2. Запустите:
   - **Windows** — двойной клик по `.exe`. При предупреждении SmartScreen: «Подробнее» → «Выполнить в любом случае».
   - **macOS** — откройте `.dmg`, перетащите `SquareRoot.app` куда удобно. При первом запуске: правый клик → «Открыть».
   - **Linux** — `chmod +x SquareRoot-linux-x86_64 && ./SquareRoot-linux-x86_64`.

Подробные требования к ОС и железу: [docs/SystemRequirements.md](docs/SystemRequirements.md).

### Запуск из исходников (любая ОС с Python 3.9+ и Tkinter)

```
git clone <адрес репозитория> SquareRoot
cd SquareRoot
python3 run_gui.py
```

Как библиотека:

```python
import squareroot
squareroot.evaluate("sqrt(2)", precision=50)   # Complex, 50 цифр
squareroot.exact_sqrt("8")                     # '2√2'
squareroot.evaluate("sqrt(x^2)")               # Expression: abs(x)
```

## Использование

1. Введите выражение под корнем: числа, `i`, `+ - * / ^`, скобки, функции
   `sqrt`, `abs`, `conj`, `re`, `im`, переменные.
2. Задайте **точность** (1–1000 значащих цифр).
3. При необходимости добавьте переменные кнопкой «+».
4. «Извлечь корень» или Enter. «Правка → Копировать результат» копирует ответ.
5. Язык меняется в меню «Язык» (по умолчанию берётся из системы).

Любая ошибка ввода (синтаксис, деление на ноль, переполнение, слишком
сложное выражение) показывается сообщением на выбранном языке, программа
не падает.

## Обновление

«Справка → Проверить обновления…» — программа один раз обращается к GitHub
и сообщает, есть ли новая версия. Если есть, открывает страницу загрузки:
скачайте новый файл и удалите старый. Автоматически в фоне ничего не
скачивается. Подробнее: [docs/Updates.md](docs/Updates.md).

## Удаление

Программа не пишет в реестр, AppData, `~/.config` и не создаёт настроек,
поэтому **удаление = удалить файл** (`.exe`, бинарник или `SquareRoot.app`).

Для гарантированного удаления со всеми возможными следами (временная папка
распаковки `_MEI…`, которая остаётся только после аварийного завершения, и
сохранённое macOS состояние окна) есть скрипты:

```
# Linux / macOS
sh packaging/uninstall/uninstall.sh [путь-к-программе]

# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -File packaging\uninstall\uninstall.ps1 [-Path путь.exe]
```

Скрипты удаляют только то, что помечено как SquareRoot (файл-маркер
`SQUAREROOT_BUNDLE` в папке распаковки), и не трогают другие программы.
