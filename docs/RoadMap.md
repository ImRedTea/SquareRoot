## Разработка v1.0 (10 рабочих дней)

| Этап | Дни | Результат |
|---|---|---|
| Старт | 1–2 | роли, архитектура, контракт API, репозиторий и CI |
| Ядро | 2–6 | комплексная арифметика, парсер, упрощение, точная форма, ошибки → **веха «Ядро готово»** |
| Интерфейс | 2–7 | макет, дизайн-документ, 5 языков, интеграция, управление точностью |
| Сборка | 5–8 | сборки для 3 ОС в CI, обновления, скрипты удаления |
| Качество | 3–8 | юнит-тесты, чёрный ящик, покрытие ≥ 95% → **feature freeze** |
| Документы | 8–9 | техническая и пользовательская документация |
| Релиз | 9–10 | регресс, v1.0.0, буфер, **сдача** |
