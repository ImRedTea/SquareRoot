# Системные требования

Поддержка намеренно ограничена платформами, для которых проект **собирает и
проверяет** программу в CI (`.github/workflows/build.yml`). Остальные
платформы не запрещены, но не поддерживаются: там программу можно запустить
из исходников (см. ниже), а ошибки на них исправляются по мере возможности.

## Готовые сборки (рекомендуемый способ)

| Платформа | Файл релиза | Архитектура | Минимальная ОС | Проверка в CI |
|---|---|---|---|---|
| Windows | `SquareRoot-windows-x86_64.exe` | x86-64 | Windows 10 (64-bit), Windows 11 | тесты + сборка на `windows-latest` |
| macOS, Apple Silicon (M1 и новее) | `SquareRoot-macos-arm64.dmg` | arm64 | macOS 13 Ventura¹ | тесты + сборка + пробный запуск на `macos-latest` |
| macOS, Intel | `SquareRoot-macos-x86_64.dmg` | x86-64 | macOS 13 Ventura¹ | тесты + сборка + пробный запуск на `macos-15-intel` |
| Linux | `SquareRoot-linux-x86_64` | x86-64 | glibc 2.39+²: Ubuntu 24.04+, Debian 13+, Fedora 40+, актуальные Arch / Manjaro / CachyOS | тесты + сборка + пробный запуск на `ubuntu-latest` |

¹ Фактическая минимальная версия macOS зависит от Python на сборочном
раннере. Она выводится в логе CI (шаг *Check architecture and minimum macOS
version*, поле `minos`). Если `minos` окажется выше 13, требование в этой
таблице поднимается до этого значения.

² PyInstaller-сборка использует glibc той системы, на которой собрана
(`ubuntu-latest` = Ubuntu 24.04). На дистрибутивах со старой glibc бинарник
не запустится, в этом случае запускайте из исходников.

### Аппаратные требования

| Ресурс | Минимум |
|---|---|
| Процессор | любой 64-битный x86-64 или Apple Silicon |
| Оперативная память | 256 МБ свободной памяти |
| Место на диске | 50 МБ (сам файл около 10–25 МБ, плюс временная распаковка при запуске) |
| Экран | 1024×768; окно программы не меньше 560×620 |
| Сеть | не нужна; используется только по кнопке «Справка → Проверить обновления» |
| Права администратора | не нужны: программа не устанавливается и не хранит на диске ни настроек, ни данных |

### Linux: графическая среда

Нужен X11 или XWayland (Tk не работает с «чистым» Wayland). В GNOME, KDE
Plasma и других распространённых окружениях XWayland включён по умолчанию.

### Неподписанные сборки

Сборки для Windows и macOS не подписаны, поэтому система предупредит при первом
запуске:

- **Windows (SmartScreen):** «Подробнее» → «Выполнить в любом случае».
- **macOS (Gatekeeper):** правый клик по приложению → «Открыть» → «Открыть».
  Либо в терминале: `xattr -dr com.apple.quarantine /путь/к/SquareRoot.app`.
- **Linux:** выдайте право на запуск: `chmod +x SquareRoot-linux-x86_64`.

## Запуск из исходников (любая ОС с Python)

Подходит для платформ без готовой сборки: Linux на ARM, старые дистрибутивы
Linux, Windows на ARM и т. п.

| Требование | Версия |
|---|---|
| Python | 3.9 или новее (в CI проверяется 3.12) |
| Tkinter | Tk 8.6 |
| Сторонние пакеты | не нужны, используется только стандартная библиотека |

Tkinter для каждой ОС:

| ОС | Как получить Python с Tkinter |
|---|---|
| Windows | установщик с python.org (Tkinter включён) |
| macOS (Intel и Apple Silicon) | установщик с python.org (universal2, Tkinter включён). Для Homebrew: `brew install python python-tk` |
| Debian / Ubuntu | `sudo apt install python3 python3-tk` |
| Fedora | `sudo dnf install python3 python3-tkinter` |
| Arch / Manjaro / CachyOS | `sudo pacman -S python tk` |

Запуск:

```
git clone <адрес репозитория> SquareRoot
cd SquareRoot
python3 run_gui.py          # на Windows: python run_gui.py
```

## Не поддерживается

- 32-битные ОС (x86, ARMv7).
- Windows 7 / 8 / 8.1: Python 3.12, на котором собран `.exe`, официально их не поддерживает.
- Windows на ARM: x64-сборка может работать через эмуляцию Windows 11, но это
  не проверялось.
- Linux на ARM (aarch64): готовой сборки нет, только запуск из исходников.

## Ограничения самой программы

| Параметр | Значение |
|---|---|
| Точность (GUI и API `squareroot.evaluate`) | 1–1000 значащих цифр (`MIN_PRECISION` / `MAX_PRECISION`) |
| Точная форма (`2√2`) | для вещественных рациональных подкоренных выражений, числитель и знаменатель до 60 цифр |
| Глубина вложенности (скобки, функции, знаки, `^`) | до 100 уровней |
| Длина цепочки операций (`a+b+c…`, `a*b*c…`) | до ~150 членов |
| Диапазон чисел | порядок до 10^999999 (дальше — ошибка «Переполнение») |

При выходе за эти пределы программа не падает, а показывает локализованное
сообщение об ошибке.
